# VrClub

Site institucional fictício de um clube de realidade virtual, feito com HTML e CSS a partir de um modelo do Figma.

Online: https://sousax.github.io/vrclub/

## O que tem

- Cabeçalho com navegação (Sobre, Local, Jogos, Preços, Contatos) e telefone de contato
- Seção principal "Explorar a Realidade Virtual" com chamadas para jogos e preços
- Seção "Sobre Nós"
- Seção "Salas de jogos"
- Rodapé com ícones de redes sociais

Os links são apenas visuais. O layout não é responsivo.

## Tecnologias

- HTML5
- CSS3
- Google Fonts (Montserrat e Dela Gothic One)

## Como rodar

Clone o repositório e abra `index.html` no navegador.
